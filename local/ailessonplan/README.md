# AI Lesson Plan

`local_ailessonplan` v0.1.0 — membuat, menyimpan, dan memublikasikan rencana pembelajaran berbantuan DALI pada Moodle 4.1+.

## Instalasi ringkas

Salin direktori ini ke `<Moodle dirroot>/local/ailessonplan`, jalankan upgrade Moodle, lalu isi DALI Base URL dan API key pada pengaturan plugin.

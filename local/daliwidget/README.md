# Dali AI Widget

`local_daliwidget` v1.4.5 — widget chat kontekstual dan pengelolaan knowledge source untuk Moodle 4.1+.

## Instalasi ringkas

Salin direktori ini ke `<Moodle dirroot>/local/daliwidget`, jalankan upgrade Moodle, lalu isi Base URL dan API key pada pengaturan plugin.

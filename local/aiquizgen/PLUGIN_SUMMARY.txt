================================================================================
DESCRIPTION
================================================================================

Plugin untuk generate soal quiz secara otomatis menggunakan OpenAI ChatGPT API.
Memungkinkan teacher/instructor untuk membuat soal berkualitas dengan cepat
berdasarkan topik tertentu.

================================================================================
KEY FEATURES
================================================================================

✓ Generate Multiple Choice, True/False, dan Short Answer questions
✓ Konfigurasi OpenAI API key di admin settings
✓ Support 3 difficulty levels (Easy, Medium, Hard)
✓ Support 2 languages (English, Indonesian)
✓ Preview questions sebelum save ke Question Bank
✓ Direct integration dengan Moodle Question Bank
✓ Activity logging untuk audit trail
✓ GDPR-compliant privacy implementation
✓ Permission-based access control
✓ Responsive dan user-friendly interface

================================================================================
CONFIGURATION OPTIONS
================================================================================

Admin Settings (Site administration → Plugins → Local plugins → AI Quiz Generator):

1. API Key (configpasswordunmask)
   - OpenAI API key
   - Required
   - Stored encrypted

2. Model (select)
   - Options: gpt-3.5-turbo, gpt-4, gpt-4-turbo
   - Default: gpt-3.5-turbo

3. Temperature (float)
   - Range: 0.0 - 2.0
   - Default: 0.7
   - Controls randomness/creativity

4. Max Tokens (int)
   - Default: 2000
   - Maximum response length

5. Max Questions per Request (int)
   - Default: 20
   - Limit for single generation

6. Enable Logging (checkbox)
   - Default: enabled
   - Log generation activities

================================================================================
USAGE WORKFLOW
================================================================================

For Teachers:
1. Navigate to course
2. Click "AI Quiz Generator" link
3. Fill generation form:
   - Enter topic/subject
   - Select number of questions
   - Choose question type
   - Select difficulty level
   - Choose language
   - Select Question Bank category
   - Add optional instructions
4. Click "Generate Questions"
5. Preview generated questions
6. Questions auto-saved to Question Bank
7. Add questions to quiz as needed

================================================================================
INTEGRATION POINTS
================================================================================

1. Course Navigation
   - Adds link via local_aiquizgen_extend_navigation_course()
   - Only visible to users with generate capability

2. Question Bank
   - Saves questions using Moodle Question API
   - Compatible with all question types
   - Supports question categories

3. Privacy API
   - Exports user generation logs
   - Deletes user data on request
   - Discloses data sent to OpenAI

# AI Quiz Generator

`local_aiquizgen` v1.1.0 — membuat draft soal dengan DALI dan menyimpannya ke Question Bank Moodle 4.1+ setelah review.

## Instalasi ringkas

Salin direktori ini ke `<Moodle dirroot>/local/aiquizgen`, jalankan upgrade Moodle, lalu isi DALI Base URL dan API key pada pengaturan plugin.

WHAT'S NEW IN v1.0.1
================================================================================

🐛 BUG FIXES
------------

1. Fixed Moodle 4.4+ Compatibility Issue
   - Problem: "Call to undefined method" error when loading generate form
   - Cause: question_category_options() moved to different namespace in Moodle 4.4
   - Solution: Added backward compatibility check with multiple fallbacks
   - Impact: Plugin now works correctly on both Moodle 4.4 and 5.0

Technical Details:
- Added runtime check for qbank_managecategories\helper class
- Falls back to core_question\local\bank\helper if needed
- Last resort fallback to questionlib function
- Zero code duplication, single codebase for all versions

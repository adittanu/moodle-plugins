LANGKAH SELANJUTNYA
================================================================================

STEP 1: INSTALL PLUGIN DI MOODLE
---------------------------------
1. Login ke Moodle sebagai administrator
2. Navigate ke: Site administration → Notifications
3. Moodle akan mendeteksi plugin baru
4. Klik "Upgrade Moodle database now"
5. Follow instalasi wizard
6. Klik "Continue"

STEP 2: KONFIGURASI OPENAI API KEY
-----------------------------------
1. Dapatkan API Key dari: https://platform.openai.com/api-keys
   - Sign up / Login ke OpenAI
   - Create new secret key
   - Copy API key (simpan dengan aman!)

2. Konfigurasi di Moodle:
   - Site administration → Plugins → Local plugins → AI Quiz Generator
   - Paste API Key ke field "OpenAI API Key"
   - Pilih Model: GPT-3.5 Turbo (recommended untuk mulai)
   - Temperature: 0.7 (default)
   - Max Tokens: 2000 (default)
   - Max Questions: 20 (default)
   - Enable Logging: Yes (checked)
   - Klik "Save changes"

STEP 3: TEST PLUGIN
--------------------
1. Buat atau masuk ke course sebagai teacher
2. Akan ada link "AI Quiz Generator" di course navigation
3. Klik link tersebut
4. Test generate 2-3 questions:
   - Topic: "Photosynthesis in plants"
   - Number: 3
   - Type: Multiple Choice
   - Difficulty: Easy
   - Language: English
   - Category: Pilih category di Question Bank
5. Klik "Generate Questions"
6. Tunggu 10-30 detik
7. Preview questions
8. Check di Question Bank - questions harus tersimpan

STEP 4: VERIFIKASI
-------------------
✓ Plugin muncul di admin plugins list
✓ Settings page bisa diakses
✓ Link muncul di course navigation (untuk teachers)
✓ Form generation bisa diakses
✓ Questions berhasil di-generate
✓ Questions tersimpan di Question Bank
✓ Logging bekerja (check database table local_aiquizgen_log)

================================================================================
TROUBLESHOOTING
================================================================================

Jika plugin tidak muncul setelah notifications:
→ Purge all caches: Site administration → Development → Purge all caches

Jika ada permission error:
→ Check file permissions: chown -R www-data:www-data /var/www/moodle5/local/aiquizgen/

Jika "API key not configured":
→ Pastikan API key sudah di-save di settings
→ Check tidak ada spasi di awal/akhir API key

Jika generation gagal:
→ Check internet connection
→ Verify API key masih valid di OpenAI
→ Check OpenAI account punya credit/billing
→ Check OpenAI API status: https://status.openai.com/

CARA PENGGUNAAN UNTUK TEACHER
================================================================================

1. Masuk ke course
2. Klik "AI Quiz Generator" di navigation
3. Isi form:
   - Topic: Topik yang spesifik (contoh: "Newton's Laws of Motion")
   - Count: 5-10 questions (untuk mulai)
   - Type: Multiple Choice (paling populer)
   - Difficulty: Medium
   - Language: Indonesian atau English
   - Category: Pilih dari Question Bank
   - Instructions: Optional, tambahkan context jika perlu
4. Klik "Generate Questions"
5. Preview results
6. Questions otomatis save ke Question Bank
7. Add questions ke quiz activity seperti biasa

Tips:
- Start dengan jumlah kecil (3-5) untuk test
- Gunakan topic yang spesifik untuk hasil lebih baik
- Selalu review questions sebelum digunakan di quiz
- Edit questions di Question Bank jika perlu penyesuaian

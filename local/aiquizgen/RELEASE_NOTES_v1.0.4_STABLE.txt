WHAT'S NEW IN v1.0.4
================================================================================

🐛 FINAL BUG FIX
----------------

Invalid Context Error Fixed:
- Error: "Invalid context id specified context::instance_by_id()"
- Root Cause: question_category_options() expects MODULE-level contexts only
- Solution: Use having_one_edit_tab_cap('editq') for proper context filtering
- Result: Only shows categories where user has permission to add questions

TECHNICAL IMPROVEMENTS
================================================================================

Context Handling Enhancement:
```php
// Before (v1.0.3):
$contexts = $contextsobj->all(); // Returns all contexts
// Problem: May include contexts without proper permissions

// After (v1.0.4):
$contexts = $contextsobj->having_one_edit_tab_cap('editq');
// Only contexts where user can actually add questions
// More secure and permission-aware
```

Benefits:
1. ✅ Only shows categories user can actually use
2. ✅ Aligns with Moodle's permission system
3. ✅ Prevents permission-related errors
4. ✅ Better security
5. ✅ Cleaner category list
